# 만들기 전에 쓰는 확인표입니다. 만든 뒤 한 줄씩 넣어 보고 그림과 글을 대조하세요.
# 아래 줄부터 복사해서 붙여 넣으세요.

| 넣는 값 | 그림이 이래야 해요 | 글이 이래야 해요 |
|---|---|---|
| 위 4분의 3 | 4칸, 왼쪽부터 3칸 칠함 | 4분의 3 / 4칸 중 3칸 |
| 위 3분의 1, 아래 6분의 2 | 칠한 끝이 같은 자리 | 3분의 1과 6분의 2는 크기가 같아요 |
| 위 5분의 2, 아래 3분의 1 | 위가 더 길게 칠해짐 | 5분의 2가 3분의 1보다 커요 |
| 위 12분의 11, 아래 2분의 1 | 두 막대 시작과 끝이 같음 | 12분의 11이 2분의 1보다 커요 |
| 분자 0 / 분자 = 분모 | 칠한 칸 없음 / 모두 칠함 | 칠한 칸이 없어요 / 모든 칸을 칠했어요 |
