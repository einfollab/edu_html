# 아래 줄부터 복사해서 붙여 넣으세요.

지금 화면에 질문 카드 뽑기 하나만 더해 줘. 번호 뽑기와 배치, 나머지는 그대로 둬.
[무엇을] 뽑힌 학생이 질문에 답하면서 오늘 배운 낱말을 다시 떠올려.
[화면에]
- 가운데 오른쪽 질문 카드에 뽑힌 질문을 크게
[누르면]
- 뽑기를 누르면 번호와 함께 아래 질문 5개 중 하나를 질문 카드에 보여 줘
- 질문 5개는 섞어서 하나씩 쓰고, 5개를 다 쓰면 다시 섞어서 처음부터 써 줘
- 다시 하기를 누르면 질문도 처음부터 다시 섞어 줘
[화면 글자]
- 질문 1: 오늘 배운 낱말 하나 말하기
- 질문 2: 친구 생각에 내 생각 더하기
- 질문 3: 오늘 배운 낱말로 짧은 문장 만들기
- 질문 4: 오늘 배운 것 중 어려웠던 것 말하기
- 질문 5: 짝에게 오늘 배운 것 한 가지 알려 주기
[지킬 것]
- 맨 위에 오늘의 목표를 한 문장으로 크게 보여 줘
- 배움과 상관없는 장식은 넣지 말고, 한 화면에 하나씩, 글자는 32px 이상으로
- 틀리면 왜 틀렸는지 한 줄로 알려 줘
- 순위표 대신 다시 하기 버튼을 넣어 줘
- 학생 정보는 저장하지 않고, 외부 파일이나 사이트 연결 없이 HTML 파일 한 장으로 만들어 줘
- 버튼을 여러 번 눌러도 한 번만 작동하게 해 줘
- 뽑기는 겹치지 않게, 골고루 섞어 줘 (피셔-예이츠 방식)
