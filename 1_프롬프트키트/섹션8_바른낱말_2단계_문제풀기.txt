지금 화면에 문제 풀기 기능 하나만 더해 줘. 배치와 글자, 나머지는 그대로 둬.
[누르면] 낱말 버튼을 누르면 맞았는지와 이유 한 줄이 나와요. 한 문제에서 한 번 고르면 다른 버튼은 눌리지 않아요. '다음 문제'를 누르면 다음 문제로 넘어가요.
[화면 글자]
맞았을 때: 맞았어요!
틀렸을 때: 다시 볼까요? (그 아래 이유 한 줄)
문제 (보기 두 개 / 정답 / 이유):
1. 며칠, 몇일 / 며칠 / '몇일'이라고 쓰지 않고 '며칠'로 써요
2. 왠지, 웬지 / 왠지 / '왜인지'가 줄어든 말이라 '왠지'예요
3. 금세, 금새 / 금세 / '금시에'가 줄어든 말이라 '금세'예요
4. 설거지, 설겆이 / 설거지 / '설겆이'가 아니라 '설거지'로 써요
5. 깨끗이, 깨끗히 / 깨끗이 / 'ㅅ' 받침 뒤에는 '이'를 써서 '깨끗이'예요
