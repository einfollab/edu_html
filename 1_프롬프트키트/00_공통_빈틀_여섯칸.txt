# 아래 줄부터 복사해서 붙여 넣으세요.

[누구에게] ( 몇 학년 무슨 과목? 어디에 띄우고 누가 누르나? 예: 초등 3학년 수학, 교실 TV에 띄우고 선생님이 누름 )
[무엇을] ( 끝나면 아이들이 무엇을 할 수 있나? 어떻게 확인하나? 예: 시계를 보고 몇 시 몇 분인지 읽는다. 열 문제 중 여덟 문제 이상 )
[화면에]
- 위: ( 오늘의 목표 문장, 몇 번째 문제인지 )
- 가운데: ( 문제와 보기, 또는 안내 )
- 아래: ( 결과 한 줄, 버튼 )
- 스크롤 없이 한 화면에, 버튼은 가로세로 2cm보다 크게
[누르면] 이번에는 배치만 볼 거야. ( 처음 멈춰 있는 화면 모습 )
[화면 글자]
- 제목: ( 내가 정한 제목 )
- 목표: ( 내가 정한 목표 문장 )
- 맞았을 때: ( 내가 정한 말 )
- 틀렸을 때: ( 내가 정한 말 + 이유 한 줄 )
- 버튼: ( 버튼 이름 )
- 끝 화면: ( 끝났을 때 문장 )
[지킬 것]
- 맨 위에 오늘의 목표를 한 문장으로 크게 보여 줘
- 배움과 상관없는 장식은 넣지 말고, 한 화면에 하나씩, 글자는 32px 이상으로
- 틀리면 왜 틀렸는지 한 줄로 알려 줘
- 순위표 대신 다시 하기 버튼을 넣어 줘
- 학생 정보는 저장하지 않고, 외부 파일이나 사이트 연결 없이 HTML 파일 한 장으로 만들어 줘
