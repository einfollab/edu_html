지금 화면에 모둠 나누기 기능 하나만 더해 줘. 배치와 글자, 나머지는 그대로 둬.
[무엇을] 번호를 섞어서 모둠을 고르게 나눠.
[화면에]
- 아래 모둠 카드 자리에 모둠 카드를 모둠 수만큼. 카드마다 '1모둠', '2모둠'과 번호 목록
[누르면]
- 모둠 나누기를 누르면 1번부터 학생 수까지의 번호를 섞어서, 모둠 인원만큼씩 나눠 줘
- 남는 사람이 1~2명이면 1모둠부터 한 명씩 더해 줘
- 남는 사람이 3명이면 3명짜리 모둠을 하나 더 만들어 줘
- 모둠 카드 안의 번호는 작은 번호부터 차례로 보여 줘
- 다시 하기를 누르면 번호를 처음부터 다시 섞어서 나눠 줘
[화면 글자]
- 모둠 이름: 1모둠, 2모둠, 3모둠 …
- 카드 안: 3번, 11번, 17번, 24번 처럼 번호 뒤에 '번'
[지킬 것]
- 맨 위에 오늘의 목표를 한 문장으로 크게 보여 줘
- 배움과 상관없는 장식은 넣지 말고, 한 화면에 하나씩, 글자는 32px 이상으로
- 틀리면 왜 틀렸는지 한 줄로 알려 줘
- 순위표 대신 다시 하기 버튼을 넣어 줘
- 학생 정보는 저장하지 않고, 외부 파일이나 사이트 연결 없이 HTML 파일 한 장으로 만들어 줘
- 버튼을 여러 번 눌러도 한 번만 작동하게 해 줘
- 뽑기는 겹치지 않게, 골고루 섞어 줘 (피셔-예이츠 방식)
