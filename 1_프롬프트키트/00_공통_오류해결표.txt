# 오류 해결표 (기본편 섹션 9). 증상을 찾고, '고치는 문장'을 복사해 캔버스에 보내세요.
# 표에 없으면: 한 일 / 일어난 일 / 원한 일 아래에 화면의 오류 글자를 그대로 붙여 보냅니다.

1. 증상: 시작 버튼을 두 번 누르면 숫자가 두 배로 빨리 줄어요
   이유: 누를 때마다 새 타이머가 하나씩 더 돌아요
   고치는 문장: 버튼을 여러 번 눌러도 한 번만 작동하게 해 줘. 다른 부분은 그대로 두고 이것만 고쳐 줘.

2. 증상: 소리가 안 나요
   이유: 브라우저는 사람이 누르기 전에는 소리를 막아요
   고치는 문장: 소리는 버튼을 누른 다음에만 나게 해 줘. 다른 부분은 그대로 두고 이것만 고쳐 줘.

3. 증상: 태블릿에서 끌어다 놓기가 안 돼요
   이유: 끌기 기능은 터치 화면에서 잘 안 돼요
   고치는 문장: 끌어다 놓기 대신, 눌러서 고르고 한 번 더 눌러서 놓게 해 줘. 다른 부분은 그대로 두고 이것만 고쳐 줘.

4. 증상: 입력칸에 한글을 쓰고 엔터를 치면 마지막 글자가 두 번 들어가요
   이유: 한글은 글자를 조합하는 중에 엔터가 먼저 처리돼요
   고치는 문장: 한글 글자 조합이 끝난 다음에 엔터가 처리되게 해 줘. 다른 부분은 그대로 두고 이것만 고쳐 줘.

5. 증상: 화면에 코드 글자가 보이고 버튼 모양이 사라졌어요
   이유: AI가 바뀐 곳만 쓰고 나머지를 빼먹었어요
   고치는 문장: 코드를 줄이지 말고 HTML 파일 전체를 처음부터 끝까지 빠짐없이 다시 써 줘. 다른 부분은 그대로 두고 이것만 고쳐 줘.

6. 증상: 코드가 중간에 끊겨서 화면이 안 나와요
   이유: 한 번에 시킨 양이 너무 많아요
   고치는 문장: 화면 1만 먼저 만들어 줘. 나머지는 내가 확인한 다음에 하나씩 부탁할게. 다른 부분은 그대로 두고 이것만 고쳐 줘.

7. 증상: 뽑기에서 같은 번호가 자주 나와요
   이유: 흔히 쓰는 짧은 섞기 코드는 고르게 섞지 못해요
   고치는 문장: 뽑기는 겹치지 않게, 골고루 섞어 줘 (피셔-예이츠 방식). 다른 부분은 그대로 두고 이것만 고쳐 줘.

8. 증상: 다음 화면으로 넘겨도 앞 타이머가 계속 돌아요
   이유: 앞 화면 타이머를 멈추는 부분이 없어요
   고치는 문장: 다음 화면으로 넘어가면 앞 화면의 타이머는 멈추게 해 줘. 다른 부분은 그대로 두고 이것만 고쳐 줘.

9. 증상: 저장한 파일을 열었더니 한글이 깨져요
   이유: 메모장에 붙여 저장할 때 글자 방식이 UTF-8이 아니었어요
   고치는 문장: (AI 말고 내가 고쳐요) 메모장에서 다른 이름으로 저장 → 인코딩 UTF-8 선택. 다음부터는 캔버스 내보내기 → 코드 다운로드로 받기
