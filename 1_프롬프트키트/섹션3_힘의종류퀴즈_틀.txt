[누구에게] 중학교 1학년 과학 시간. 학생이 각자 태블릿이나 노트북으로 열어서 혼자 풀어요.
[무엇을] 상황에 맞는 힘의 종류를 고를 수 있다. 네 문제 중 세 문제 이상 맞히면 이해한 것으로 봐요.
[화면에] 위: 오늘의 목표와 몇 번째 문제인지(예: 1/4) / 가운데: 문제 문장과 보기 버튼 3개 / 아래: 결과 한 줄과 '다음 문제' 버튼
[누르면] 보기 버튼을 누르면 맞았는지 바로 보여 줘. 틀리면 내가 고른 보기에 맞는 이유를 아래 표에서 찾아 한 줄로 보여 줘. '다음 문제'를 누르면 다음 문제가 나와. 네 문제가 끝나면 맞힌 개수와 '다시 풀기' 버튼을 보여 줘.
[화면 글자]
- 제목: 힘의 종류 확인 문제
- 목표: 상황에 맞는 힘의 종류를 고를 수 있다
- 맞았을 때: 정답입니다
- 틀렸을 때: 다시 생각해 봅시다 (그 아래에 이유 한 줄)
- 버튼: 다음 문제 / 다시 풀기
- 끝 화면: 네 문제 중 ○문제를 맞혔습니다
- 문제 표 (문제, 보기, 정답, 이유는 이 표대로만 써 줘)
| 문제 | 보기 | 정답 | 틀린 보기를 골랐을 때 이유 |
| 책상 위 책을 살짝 밀어도 미끄러지지 않는 이유는? | 중력 / 마찰력 / 탄성력 | 마찰력 | 중력: 중력은 물체를 아래로 당기는 힘이에요 / 탄성력: 탄성력은 늘어나거나 눌린 물체가 원래대로 돌아가려는 힘이에요 |
| 손에서 놓은 사과가 땅으로 떨어지는 이유는? | 마찰력 / 탄성력 / 중력 | 중력 | 마찰력: 마찰력은 닿아 있는 면에서 움직임을 방해하는 힘이에요 / 탄성력: 탄성력은 늘어나거나 눌린 물체가 원래대로 돌아가려는 힘이에요 |
| 당겼다 놓은 고무줄이 원래 길이로 돌아가는 이유는? | 탄성력 / 중력 / 마찰력 | 탄성력 | 중력: 중력은 물체를 아래로 당기는 힘이라 고무줄을 줄어들게 하지 않아요 / 마찰력: 마찰력은 닿아 있는 면에서 움직임을 방해하는 힘이에요 |
| 굴러가던 공이 잔디밭에서 점점 느려지다 멈추는 이유는? | 중력 / 탄성력 / 마찰력 | 마찰력 | 중력: 중력은 아래로 당기는 힘이라 앞으로 굴러가는 공을 멈추게 하는 힘이 아니에요 / 탄성력: 탄성력은 늘어나거나 눌린 물체가 원래대로 돌아가려는 힘이에요 |
[지킬 것]
- 맨 위에 오늘의 목표를 한 문장으로 크게 보여 줘
- 배움과 상관없는 장식은 넣지 말고, 한 화면에 하나씩, 글자는 32px 이상으로
- 틀리면 왜 틀렸는지 한 줄로 알려 줘
- 순위표 대신 다시 하기 버튼을 넣어 줘
- 학생 정보는 저장하지 않고, 외부 파일이나 사이트 연결 없이 HTML 파일 한 장으로 만들어 줘
- 버튼을 여러 번 눌러도 한 번만 작동하게 해 줘
- 색만으로 구분하지 말고 글자도 함께 보여 줘
