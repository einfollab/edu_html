# 말로 만드는 수업 도구 · 기본편

> **정답은 선생님이, 화면은 AI가.**
> 코딩을 몰라도 수업 도구는 만들 수 있어요.

초·중·고 선생님이 **무료 제미나이 캔버스**로, 내 수업에 필요한 도구(HTML 파일 한 장)를 말로 만들고, 눌러 보고, 고치고, 저장하는 방법을 배우는 강의입니다.
코드를 외우거나 문법을 배우는 시간은 없습니다.

| | |
|---|---|
| **대상** | HTML을 한 줄도 몰라도 되는 초·중·고 선생님 |
| **시간** | 3시간 (기본편) |
| **도구** | 제미나이 캔버스 (무료 계정, 개인 계정 권장) |
| **준비물** | 노트북 또는 태블릿 하나 |
| **강사** | 조성문 (아인폴랩 AI연구소) |

이어서 듣는 **심화편**(5시간)도 있습니다. 기본편 마지막 섹션에서 안내합니다.

---

## 이 강의가 끝나면

1. 내 수업에 맞는 도구를 **직접 만든다**
2. 만든 도구를 **눌러 보고, 고치고, 저장한다**
3. 학생 정보 없이 **안전하게 쓴다**

교실 TV에 띄우거나 학생 태블릿에서 열면 바로 쓸 수 있는 HTML 파일 한 장짜리 도구를 만들게 됩니다.

## 만드는 순서

이 강의에서 하는 일을 요즘 말로 *바이브코딩*이라고 합니다. 코드를 직접 쓰지 않고, 말로 시키고, 나온 화면을 보며 고쳐 가는 방식입니다.

```
① 재료 준비      목표 · 정답표 · 지킬 것
      ↓
② 말로 설명      프롬프트 틀에 채워 보내기
      ↓
③ 눌러 보기  →  ④ 본 대로 하나씩 고치기  →  ⑤ 저장 (이름_1.html, _2.html …)
      └──────────── 세 번쯤 반복하면 수업에 쓸 만해집니다 ────────────┘
```

### 섹션별 자세히

<details>
<summary><b>섹션 0. 시작하기 전에</b></summary>

- 0-1 이 강의로 만드는 것
- 0-2 오늘 강의 진행 방식
- 0-3 준비물
- 0-4 수업 자료 받기와 프롬프트 키트 쓰는 법

</details>

<details>
<summary><b>섹션 1. 처음 만나는 제미나이 캔버스</b></summary>

- 1-1 한 줄로 30초 만에 수업 도구 만들기
- 1-2 캔버스 화면 구성과 미리보기에서 눌러 보기
- 1-3 완성본 고쳐 보기
- 1-4 HTML은 글자 파일이다
- 1-5 저장하기: 잘 될 때마다 HTML로
- 1-6 무료 계정은 작은 모델: 잘게, 정확히 말하기

</details>

<details>
<summary><b>섹션 2. 왜 이렇게 만드나</b></summary>

- 2-1 앱으로 만들 가치가 있나: 세 가지 질문
- 2-2 목표부터 정한다: 목표 → 확인 방법 → 활동
- 2-3 초안은 AI가, 확정은 교사가, 화면은 AI가
- 2-4 학생 정보를 받지 않는 이유

</details>

<details>
<summary><b>섹션 3. 프롬프트와 만들기 흐름</b></summary>

- 3-1 만들기 4단계, 세 번 고치면 됩니다
- 3-2 프롬프트 틀 여섯 칸: 지킬 것은 맨 끝에
- 3-3 프롬프트 원칙 5가지
- 3-4 지킬 것 5줄과 자주 나는 실수 미리 알리기
- 3-5 화면 글자는 선생님이 정합니다

</details>

<details>
<summary><b>섹션 4. 예제 ① 안내판: 화면 하나 만들기</b></summary>

- 4-1 [초등편] 학습 안내판 + "알아요/조금/몰라요" 버튼
- 4-2 [중고등편] 차시 안내 + 평가 기준 체크리스트
- 4-3 정리

</details>

<details>
<summary><b>섹션 5. 예제 ② 뽑기: 입력칸과 무작위</b></summary>

- 5-1 [초등편] 번호 + 질문 카드 함께 뽑기
- 5-2 [중고등편] 모둠·역할 배정기
- 5-3 정리: 이름 대신 번호, 중복 없이 뽑기

</details>

<details>
<summary><b>섹션 6. 예제 ③ 타이머: 버튼과 첫 오류 고치기</b></summary>

- 6-3 실제 오류 고치기: 내가 눌러 보고 본 대로 말하기

## 이 강의의 약속 다섯 가지

- **정답은 선생님이 확정합니다.** AI는 초안만 쓰고, 문제와 정답은 선생님이 교과서 옆에 두고 점검합니다.
- **프롬프트 틀 여섯 칸**을 쓰고, **지킬 것은 맨 끝**에 둡니다.
- **한 번에 하나만** 시킵니다. 배치 → 꾸밈 → 기능, 세 단계로 나눠 보냅니다.
- **본 대로 말합니다.** 눌러 보고 *한 일 / 일어난 일 / 원한 일*을 세 줄로 말해 고칩니다.
- **학생 정보를 받지 않습니다.** 이름 대신 번호, 저장하지 않기.

## 수업 자료 (프롬프트 키트)

강의에 나오는 프롬프트와 파일을 한 묶음으로 드립니다. **키트는 그대로 쓰는 게 아니라 내 수업에 맞게 고쳐 쓰는 것**입니다.

```
수업자료_기본편_섹션0-9/
├─ 읽어주세요.txt
├─ 00_혼자할때_한장안내          혼자 따라 할 때 보는 한 장 안내 (docx · pdf)
├─ 1_프롬프트키트/
│   ├─ 00_공통_*                 빈 틀 여섯 칸, 머리말, 지킬 것 다섯 줄, 프롬프트 도우미,
│   │                            고칠 때 본 대로 말하기, 오류 해결표, 용어집 …
│   └─ 섹션1_* ~ 섹션7_*         섹션별 프롬프트 (1·2·3단계, 고침 세 줄, 한 걸음 더)
├─ 2_예제완성HTML/               무료 계정으로 실제 만든 결과. 막혔을 때 비교용
├─ 3_실습용_고장파일/             고장 난 파일을 열어 눌러 보고 고치는 연습
└─ 섹션8_실습지                  한 장 기획서와 점검표 (docx · pdf)
```

## 이렇게 공부하세요

1. 섹션 0에서 수업 자료를 받고 **개인 구글 계정**(학교 계정 말고)으로 제미나이를 엽니다.
2. 슬라이드를 보면서 **한 단계씩 따라 합니다.** 화면이 강의와 조금 달라도 정상입니다. 같은 프롬프트라도 결과는 매번 조금씩 달라요.
3. 막히면 **오류 해결표**(섹션 9)부터 펼쳐 봅니다. 표에 없으면 오류 문구를 그대로 붙여 AI에게 물어보세요.
4. 섹션 8에서 **내 수업에 필요한 도구 하나**를 직접 만듭니다.
